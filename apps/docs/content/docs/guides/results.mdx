---
title: Review results
description: Find delivery status, inbox activity, and analytics.
---

Open **Publications** to inspect delivery for each destination. Open **Inbox** for comments, replies, messages, and notifications when those features are enabled for the account.

Open **Analytics** to view account and post metrics collected from connected providers. Analytics starts disabled for new accounts. Enable it in account details, then allow the first refresh to finish. Providers expose different metrics and update them at different times.

Open **Grow** for recommendations on eligible Bluesky and Mastodon accounts. OpenPost never follows automatically. Every follow is an explicit action.

Historical data remains stored when you disable an optional feature. Disabling it stops future provider reads and writes until you enable it again.
