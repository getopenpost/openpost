Choose the task you want to automate. Each walkthrough starts with a template and creates a draft for review.

- [Build your first workflow](/workflows/first-workflow): prepare an announcement for a GitHub release.
- [Prepare a weekly feed digest](/workflows/examples/feed-digest): collect several articles into one draft.
- [Share only relevant releases](/workflows/examples/relevant-releases): use an AI decision to filter releases.
- [Turn an API response into a post](/workflows/examples/api-to-post): fetch and format data from another service.

Use [Preview and test](/workflows/testing) before activating any template. To extend a draft-and-review template, follow [Review and schedule posts](/workflows/review-and-schedule).
