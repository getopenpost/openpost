Sign in at [app.openpo.st](https://app.openpo.st) and create a workspace. Have one social account ready to connect and a short post to publish. If you run your own server, finish [installation and provider setup](/self-hosting) first.

## 1. Connect an account

Open **Settings → Workspace → Social accounts**, choose a platform, sign in, and approve access. For password-based connections such as Bluesky, follow the [account guide](/guides/accounts).

## 2. Create a publication

Choose **New post**, select the workspace and account, and write your text. Add media or a thread when needed. Review the destination preview before sending it.

## 3. Publish or schedule

Choose **Publish now** for an immediate delivery, or choose a date and time and select **Schedule**. Open **Calendar** to see scheduled work.

## 4. Check the result

Open **Publications** and select your post. Check the status for each account. **Published** means that destination was delivered; **Scheduled** means it is waiting for its chosen time.

If an account shows **Failed**, open that destination for the provider error and recovery action. You can retry that destination without republishing the accounts that succeeded. See [publishing troubleshooting](/guides/troubleshooting) if the error is unclear.

## Self-hosted first run

Follow the [self-hosting quickstart](/self-hosting), then use the same four steps. The first account created on a new instance becomes its administrator.
