title: Trim with Quick Cut
description: Keep the parts you need and export a cut without unnecessary re-encoding.
icon: Scissors
---

Open [Quick Cut](https://app.openpo.st/quick-cut) when you need to keep specific sections of a video or audio file. Add one or more source files, mark the ranges to keep, then download each cut or merge compatible cuts into one output. Quick Cut tells you before export whether it can copy the encoded streams or needs to re-encode them.

Use [OpenPost Video Editor](/guides/video-editor) when the edit changes pixels, speed, audio levels, transitions, captions, overlays, or effects.

## Mark the sections to keep

Set **In** and **Out** points with the player or time fields, then add the segment. You can enable, reorder, and preview segments in sequence. The stream panel lists the video, audio, subtitle, data, and unknown tracks in each source.

**Nearest keyframe** snaps an eligible segment start to a verified source keyframe so encoded packets can be copied. **Exact time** keeps the requested boundary and uses precise transcoding when stream copy cannot represent it. The preflight states which segments can be copied, which require encoding, and why an output is blocked.

## Check the export plan

If a segment can use stream copy, Quick Cut keeps its encoded video and audio packets. It preserves compatible source containers and codecs, so an eligible MOV stays MOV and an eligible WebM stays WebM. This avoids the quality loss and render time of another encode.

Quick Cut blocks an export that would silently drop unsupported subtitle, data, unknown-audio, or extra-video streams. A merged export needs compatible selected streams across its sources. For an exact boundary that cannot be copied, choose the precise export path. For incompatible sources or edits to the picture or mix, use the full [Video Editor](/guides/video-editor).

Exports can download directly or save into the selected Video Editor workspace. A Quick Cut project file keeps source metadata, segment order, cut mode, and export choices. Reopening still requires access to the original source files.

## Add the result to OpenPost

When signed in with an OpenPost Workspace selected, **Send to OpenPost** uploads the finished output to Media. It does not upload the Quick Cut project or source files.

Quick Cut uses browser media and file APIs. Current Chrome or Edge gives the most complete file, codec, and workspace support.
