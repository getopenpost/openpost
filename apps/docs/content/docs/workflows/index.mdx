Open **More → Workflows** in your workspace, or [open Workflows](https://app.openpo.st/workflows). Build an automation using your connected accounts, add a review step, and inspect each run.

## Start with a draft

[Build your first workflow](/workflows/first-workflow) to turn a GitHub release into a draft that waits for review. You can preview it before activating it.

A **trigger** decides when a workflow starts. A **step** uses the trigger's data or an earlier step's output. A **run** is one execution, with its own inputs, results, and history.

Publishing a workflow activates the automation. A social post reaches its destinations only when the workflow schedules it or you publish it from Publications.
