Choose your client below. Use [MCP connection setup](/mcp/mcp-guide) for shared permissions, self-hosted URLs, and the local bridge. After setup, ask the assistant to list your workspaces, then review the schedule for a named workspace without changes.

## Editors and agents

[Codex](/mcp/codex) shares MCP configuration across its CLI, IDE extension, and desktop app on the same host. Add remote MCP once, authenticate in the browser, and start a new session.

[Claude Code](/mcp/claude-code) adds OpenPost as a remote server with user scope across your projects. Run `/mcp` to sign in, and use the local bridge only when your instance is reachable from that machine.

[Cursor](/mcp/cursor) supports remote Streamable HTTP servers in personal or project configuration. Complete OAuth in the browser, or fall back to environment-interpolated token headers when OAuth is unavailable.

[VS Code](/mcp/vs-code) manages the MCP connection and browser sign-in from the editor. Add an HTTP server, enable its tools in agent chat, and inspect status with **MCP: List Servers**.

[GitHub Copilot](/mcp/github-copilot) reuses the [VS Code connection](/mcp/vs-code) in Copilot agent mode. GitHub-hosted coding agents have separate MCP configuration and do not inherit the editor connection.

[Gemini CLI](/mcp/gemini-cli) uses `httpUrl` with OAuth for Streamable HTTP. Authorize from the CLI and retry authorization when the login expires or the browser callback cannot reach the host.

[Devin](/mcp/devin) adds OpenPost in the MCP marketplace with HTTP and OAuth. Cloud Devin needs public HTTPS and cannot reach `localhost` on your laptop.

[Antigravity](/mcp/antigravity) runs the local `openpost-mcp` bridge for Hosted or a self-hosted instance your computer can reach. Save the raw MCP config, then refresh servers or restart the app.

[OpenCode](/mcp/opencode) adds OpenPost as a remote entry under `mcp` and opens browser sign-in on first use. Authorize, list, and debug the server from the CLI when authentication expires.

[OpenClaw](/mcp/openclaw) registers OpenPost on the machine running the agent with `mcp set`, then logs in and probes with `doctor`. Finish login on the gateway host for remote setups.

[Hermes Agent](/mcp/hermes) configures OAuth in `config.yaml` and authenticates as the user running the gateway. Restart the session or reload MCP tools after sign-in.

## Verify access

Request an unpublished draft for your first write and inspect it in OpenPost. Check the workspace, accounts, text, media, and time before approving a schedule or publish action. For missing tools, expired credentials, or delivery failures, use [Tasks and troubleshooting](/mcp/mcp-guide/use-cases).
