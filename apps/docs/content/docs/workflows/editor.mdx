Open a workflow and select a node to configure it. Changes save automatically; **Saved** confirms the server received them. Resolve any edit conflict before continuing.

## Add and arrange steps

- Select **Add step**, a node's plus button, or drag its output dot to empty space.
- Select **Recipes** to insert connected steps, such as AI writing with review or review with scheduling. You can edit each inserted step.
- Select **Organize** to tidy the canvas without changing execution order.
- Right-click a node, or focus it and press Shift+F10, to configure, duplicate, delete, or add a step after it.
- Rename a step in its configuration header.

On a phone, switch between **Input**, **Configure step**, and **Output**. Use **Back to canvas** when finished.

Publish again to apply draft changes to future automatic runs. Existing runs keep the definition they started with.

## Branches

Conditions and AI decisions choose a Yes or No path, then continue with the following step. A step can use source data and earlier outputs on its own path. Missing data fails the step.

Text equality is exact. Number and boolean comparisons accept values such as `10` and `true`. **Contains** ignores case. Numeric comparisons require finite numbers.

## Keyboard shortcuts

| Action                   | Shortcut               |
| ------------------------ | ---------------------- |
| Open a focused node      | Enter                  |
| Undo                     | Ctrl+Z                 |
| Redo                     | Ctrl+Shift+Z or Ctrl+Y |
| Save                     | Ctrl+S                 |
| Duplicate a focused node | Ctrl+D                 |
| Delete a focused node    | Delete or Backspace    |

On macOS, use Command instead of Ctrl. Inside a text field, undo and redo affect that field.
