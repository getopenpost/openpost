## Use OpenPost

- [Connect your accounts](/guides/accounts).
- [Write and publish a post](/guides/publishing), or [schedule it](/guides/publishing#schedule-and-calendar).
- [Upload and reuse media](/guides/media-library).
- [Check delivery and fix failures](/guides/troubleshooting).
- [Read analytics](/guides/analytics) and [reply in Inbox](/guides/inbox).
- [Manage workspace access](/guides/workspaces).

## Connect another tool

Use [an AI assistant](/mcp), [the TypeScript SDK, HTTP API, CLI, or n8n](/automate). The [API reference](/api-reference) lists operations and schemas.

## Run your own instance

[Install OpenPost](/self-hosting), [configure services](/self-hosting/configuration), then [set up backups and upgrades](/self-hosting/maintenance). Network credentials belong in the [integration setup guides](/self-hosting/integrations).
