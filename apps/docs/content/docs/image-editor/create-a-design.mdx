Choose where the design should be saved, then pick a social format, template, or image.

## Start without signing in

Open [Image Editor](https://app.openpo.st/image-editor). Pick a format, choose a template, or import a PNG, JPEG, or WebP image.

Public designs and imported files stay in this browser. Clearing site data or using private browsing can remove them. To keep an editable copy in a workspace, choose **Save to OpenPost** and sign in. The browser copy stays on this device.

## Start in a workspace

Open **Media → Create → Create design**, or open an image in Media and choose to edit it. Editing leaves the original file unchanged.

Workspace designs autosave to OpenPost and reopen from Media. They can use workspace media, templates, brand colors, and fonts.

## Start from a post

1. Open the post's media picker, then **Create → Image Editor**. OpenPost saves the draft before opening the editor.
2. Create the design and check its page order.
3. Choose **Export and attach** to return the files to the same post, thread part, or thumbnail field.

The editor checks the destination limits again before attaching files.

## Choose a size

Use a social preset or enter custom pixel dimensions. Add a solid, transparent, gradient, or image background, then [add layers](/image-editor/layers). Each design supports up to 35 pages, which can have different sizes.

Image Editor works with still images and pixel dimensions. Use [Video Editor](/video-editor) for animation or video. Use a print tool for CMYK, bleed, or physical units. Arbitrary SVG files and remote image links cannot be added as layers.

## Find the controls

On desktop, the top bar holds the save state, undo, redo, Color, and Export. Add content from the left tool rail. **Layers** and **Properties** on the right provide keyboard-accessible controls for order and exact values. The bottom page strip selects and orders pages.

On a phone, the bottom tool rail opens one editing sheet at a time. Use one finger to transform a selected layer and two fingers to pan or zoom.

Zoom and pan change your view only. Guides and safe areas do not appear in exports. Check the save status before closing the tab. See [saving and recovery](/image-editor/saving-and-recovery) if saving fails.
