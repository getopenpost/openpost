title: Create and publish
description: Write, review, and publish destination-specific versions of a publication.
icon: PenLine
---

Choose **New post** in the workspace where you want to publish. Select one or more connected accounts and write your starting text. OpenPost creates a separate destination version, called a rendition, for each account. You can change its wording, media, format, and provider settings before sending it.

## Make each destination ready

Open each destination preview. Check the text, media order, format, and account-specific options. A file or format that works for one provider may not work for another. The composer shows available options for the connected account and explains limits it can detect.

## Save a draft or write a thread

Leave a publication as a draft if it needs review. OpenPost saves draft changes while you work; find it later in **Publications**. For a thread, add segments in the order readers should see them and check the complete sequence for each destination.

## Media

Upload files in the composer or reuse a file from [Media](/guides/media). Make still designs in the Image Editor, or prepare video in the Video Editor or Quick Cut. The composer checks the selected accounts' media rules before publishing.

## Publish

Choose **Publish now** when every destination is ready. Or [schedule the publication](/guides/scheduling) for later. Open **Publications** to check the status of each destination. If one fails, read its error and retry only that destination.
