---
title: Create and publish
description: Write, review, and publish destination-specific versions of a publication.
icon: PenLine
---

Open **New post** and choose a workspace. Select one or more connected accounts, then write the source text. OpenPost creates a rendition for each destination so you can adjust wording, media, and provider options before publishing.

## Review before sending

Check the preview for every account. Provider limits, account permissions, and media rules can differ. OpenPost keeps unsupported actions out of the editor and explains missing access when it can.

## Drafts and threads

Leave a publication as a draft while you work. Add thread segments in order and review the complete sequence before publishing. OpenPost saves draft changes automatically while you work. Find unfinished posts in **Publications**, then open a draft to keep editing. Review each destination before publishing, because its text, media, and provider options can differ.

## Media

Upload files in the composer or choose existing files from [Media](/guides/media). Use the image editor for still designs and the video editors for longer work. Provider-specific media requirements appear beside the affected rendition.

## Publish

Choose **Publish now** after review. Open **Publications** to inspect delivery. A failure on one destination does not hide the outcome of the others.
