Open **More → Workflows** in your workspace. Workflows uses your connected accounts and workspace access.

[Build your first workflow](/workflows/first-workflow) to create a release announcement that waits for review.

## Build and run

- [Edit the canvas](/workflows/editor) and [pass data between steps](/workflows/variables).
- [Choose a trigger](/workflows/triggers), [use AI](/workflows/ai), or [call an API](/workflows/connections).
- [Preview and test](/workflows/testing) before activating automatic runs.
- [Review and schedule posts](/workflows/review-and-schedule), then [inspect runs or manage reposts](/workflows/runs).

## Examples

- [Prepare a weekly feed digest](/workflows/examples/feed-digest).
- [Share only relevant releases](/workflows/examples/relevant-releases).
- [Turn an API response into a post](/workflows/examples/api-to-post).

For automation outside OpenPost, use the [SDK, API, CLI, or n8n](/automate). To work through a chat or coding assistant, see [AI assistants](/mcp).
