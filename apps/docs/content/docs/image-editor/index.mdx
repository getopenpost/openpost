OpenPost Image Editor makes single images and multi-page carousels. You can start without an account, work from workspace media, or open it from a post and attach the result when you finish.

[Open the Image Editor](https://app.openpo.st/image-editor) to start with a social format, a template, or an image. Exports have no watermark.

## Start

- [Create a design](/image-editor/create-a-design) from a preset, template, or existing image.
- [Learn the editor layout](/image-editor/editor-layout) on desktop and phone.

## Edit

- [Arrange layers](/image-editor/layers) for text, images, shapes, paint, and groups.
- [Build a carousel](/image-editor/pages-and-carousels) and set the page order.
- [Adjust color and effects](/image-editor/color-and-effects), crop images, and remove backgrounds.
- [Reuse templates and brand items](/image-editor/templates-and-brand).

## Finish

- [Export or attach the result](/image-editor/export-and-publish) to a publication.
- [Understand saving and recovery](/image-editor/saving-and-recovery) before changing devices or restoring an older version.
- [Check the editor limits](/image-editor/limits) when a format or workflow is not available.

OpenPost Image Editor edits still images. Use [Video Editor](/video-editor) for composed video or [Quick Cut](/video-editor/quick-cut-and-recorder#trim-with-quick-cut) when you only need to remove parts of a compatible video.
