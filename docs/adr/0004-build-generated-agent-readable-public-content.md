# Build agent-readable representations from public content

OpenPost generates faithful semantic Markdown representations and curated discovery indexes from the canonical public marketing and documentation sources through one shared contract invoked by each owning build. Public knowledge receives HTML and Markdown, while private operations remain available through the authenticated app, HTTP API, CLI, or MCP; OpenAPI and MCP remain authoritative native interfaces rather than being flattened into Markdown, and the app host does not publish an agent-content index. This avoids manually maintained mirrors and runtime conversion while preserving independently deployable marketing and documentation artifacts. The marketing and documentation origins publish an affirmative search, AI input, model-training, and attributed-reference preference for public content; crawler analytics, crawler identity verification, app request telemetry, and server-side versions of browser tools remain outside this system, and the edge operator must keep its bot and managed-robots policies aligned with the origin preference.
