Choose a connection your assistant can use. Keep one connection per task so the instance, workspace, and permissions are clear.

| Connection                    | Requirements                           | Use it for                                   |
| ----------------------------- | -------------------------------------- | -------------------------------------------- |
| [MCP](/mcp/mcp-guide)         | Remote HTTP MCP or a local MCP command | OpenPost tools inside a conversation         |
| [OpenPost skill](/mcp/skills) | Agent Skills and terminal access       | OpenPost instructions for a coding assistant |
| [CLI](/automate/cli)          | Terminal access                        | Scripts, CI, and exact command sequences     |

MCP supplies live tool schemas and uses OAuth or a token. The skill supplies operating instructions for the installed CLI, which uses a saved profile or `OPENPOST_TOKEN`. It does not install the CLI, authenticate MCP, or store credentials. You do not need the skill when the assistant already has a working MCP connection.

## Choose your client

Chat assistants: [ChatGPT](/mcp/chat-assistants#chatgpt), [Claude web](/mcp/chat-assistants#claude-web), [Claude Desktop](/mcp/chat-assistants#claude-desktop), [Grok](/mcp/chat-assistants#grok), and [Perplexity](/mcp/chat-assistants#perplexity).

Coding assistants: [Codex](/mcp/coding-assistants#codex), [Claude Code](/mcp/coding-assistants#claude-code), [Cursor](/mcp/coding-assistants#cursor), [VS Code and Copilot](/mcp/coding-assistants#vs-code-and-github-copilot), [Gemini CLI](/mcp/coding-assistants#gemini-cli), [Devin](/mcp/coding-assistants#devin), [Antigravity](/mcp/coding-assistants#antigravity), [OpenCode](/mcp/coding-assistants#opencode), [OpenClaw](/mcp/coding-assistants#openclaw), and [Hermes Agent](/mcp/coding-assistants#hermes-agent).

After connecting, ask the assistant to list your workspaces. Name one and request a schedule review without changes. Grant write access when you need a draft or another change.

For an application integration, use the [SDK](/automate/sdk) or [HTTP API](/automate/api).
