# Video editor parity: mask editor + power window

- Mask shapes now open a dedicated Mask canvas tool: Pen/Draw-new mode switch,
  direction-preserving smooth conversion, corner conversion, and point deletion,
  all with atomic undo and topology/keyframe guards.
- Power window has a bespoke pane (shape, window, matte, correction groups) with
  a UV-space gizmo preview; center/size drags preview live and commit atomically.
