---
title: Share only relevant releases
description: Filter GitHub releases with an AI decision before drafting a post.
icon: Workflow
---

Open **More → Workflows → Start from a template**. Use **Review relevant updates with AI** to decide whether a release deserves a post.

1. Set the GitHub repository on the trigger. For a private repository, select a saved GitHub connection.
2. Open **AI decision** and describe your criteria. For example: "Choose Yes for a new feature users can try. Choose No for dependency updates, internal refactors, or documentation-only changes."
3. Keep **Create draft** and **Review post** on the **Yes** path. The empty **No** path finishes without a draft.
4. Fetch an example release. **Test node** makes a real AI call and shows Jev's decision and probability. Try examples you would accept and reject.
5. Choose destinations in **Create draft**, preview the full path, and publish when it behaves as expected.

AI decisions can be wrong. Keep the review step before scheduling. Preview decisions are examples; use node tests to evaluate real decisions and inspect their recorded usage.
