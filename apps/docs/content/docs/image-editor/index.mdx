[Open Image Editor](https://app.openpo.st/image-editor) to make a still image or a carousel. You can start without signing in. Exports have no watermark.

1. [Create a design](/image-editor/create-a-design) from a format, template, image, or post.
2. [Add and arrange layers](/image-editor/layers), or [build a carousel](/image-editor/pages-and-carousels).
3. [Adjust color and effects](/image-editor/color-and-effects).
4. [Export or attach the result](/image-editor/export-and-publish).

Use [templates and brand items](/image-editor/templates-and-brand) for repeated layouts. Read [saving and recovery](/image-editor/saving-and-recovery) before clearing browser data or restoring a design.

Use the built-in Assistant or [a connected MCP assistant](/mcp/mcp-guide/media#edit-an-open-project) for supported edits. You see changes live and can review or undo them in the editor. Keep the project open while it works.
