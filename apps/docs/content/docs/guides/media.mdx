Open **Media** to upload files, search the library, add tags, and see where an asset is used. Media belongs to a workspace, so switch workspaces before looking for a file.

Use the image editor for multi-page still designs, templates, brand assets, background removal, and export. Use the video editor for timeline edits, captions, audio, color, and export. Quick Cut makes exact cuts from a source. Recorder captures screen, camera, and microphone sources.

After export, send the result back to the composer or choose it from Media. Check the destination preview because providers accept different formats, sizes, and attachment counts.

OpenPost does not delete a file that a publication or editor still uses. Remove unused files from Media after checking their usage.

## Choose the right tool

| What you want to do | Start here |
| --- | --- |
| Find, tag, or reuse an upload | [Media library](/guides/media-library) |
| Make a post image or carousel | [Image Editor](/guides/image-editor) |
| Combine clips, audio, text, and captions | [Video Editor](/guides/video-editor) |
| Remove unwanted ranges from a recording | [Quick Cut](/guides/quick-cut) |
| Capture a screen, camera, or microphone | [Recorder](/guides/recording) |

For an existing publication, open its media picker before starting an image design. **Export and attach** can then return the finished images to that publication. Video exports use **Send to OpenPost**, followed by **Open composer**.
