Changes save automatically. **Saved** confirms the current draft reached the server. If another editor changes the same workflow, resolve the conflict before continuing.

## Add and configure steps

Draft edits take effect for automatic runs when you publish the workflow again. Runs already started retain their original definition. Select a node on the canvas, or focus it with the keyboard and press Enter. The editor fills the window. Select **Add step**, use a node's plus button, or drag its output dot to empty space to choose the next node. On a phone, switch between **Input**, **Configure step**, and **Output**, then use **Back to canvas**.

Use **Organize** at the top left to tidy the canvas without changing execution order. Right-click a node, or press Shift+F10 while it has focus, to configure, add after, duplicate, or delete it. Undo and redo apply to these edits and canvas moves. Rename a step directly in its modal header.

## Keyboard shortcuts

Use Ctrl+Z to undo, Ctrl+Shift+Z or Ctrl+Y to redo, and Ctrl+S to save. On macOS, use Command instead of Ctrl. With a node focused, Delete or Backspace removes it and Ctrl+D duplicates it. Inside a text field, undo and redo affect that field only.

## Recipes and branches

The **Recipes** category adds connected steps together: write a draft with AI and review it, review and schedule a post, or prepare a feed digest. Each inserted step remains editable. Recipes also include JavaScript presets for removing duplicates and joining text.

A condition or AI decision has a Yes path and a No path. After the chosen path finishes, the run continues with the following step. Fields can refer to source data or an earlier step on the same path. Missing data fails the step instead of silently substituting an empty value.

For equality conditions, a number or boolean from an earlier step accepts the corresponding entered value, such as `10` or `true`. Two text values use exact text equality. **Contains** ignores letter case. Numeric comparisons reject values that cannot be read as finite numbers.
