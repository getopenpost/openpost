# Public OpenPost Studio

- Scope and mode: Operate surface at `/studio`, with a Persuade entry on the marketing tools site. The authenticated workspace Studio remains the same editor and visual system.
- Audience and job: Anonymous social creators need to start from a format, local image, or built-in template, edit without an account, return to browser-saved work, and export a clean file.
- Primary action and proof: Start a local design immediately. The working editor, local save state, clean download, and optional background removal prove the offer.
- Direction: A compact local workbench. Recent local designs lead for returning visitors; format, image import, and templates lead for first-time visitors. The memorable moment is entering the full editor without an auth interruption.
- Constraints: One Studio codebase, local document/media storage, no watermark or export gate, privacy-safe Umami events, explicit browser-storage caveat, responsive touch controls, and an explicit copy-to-workspace migration after authentication.
