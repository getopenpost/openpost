---
title: Templates and brand items
description: Reuse layouts, workspace colors, and custom fonts.
---

Save a template to reuse an editable layout. Use the workspace brand kit for shared colors and fonts.

## Make a template

Open a workspace design and save it as a new template, or replace an existing template. Starting from a template creates a separate design. Later template changes leave existing designs and exports unchanged.

Use clear layer names for content that changes between designs. To edit a layout again, reopen its source design or template rather than its flattened export.

## Use the brand kit

Manage colors, page backgrounds, text styles, and WOFF2, TTF, or OTF fonts in **Settings → Workspace → Brand**.

Saved colors appear in the editor's color controls, and saved fonts appear in text controls. Page backgrounds and whole-layer text styles do not yet have direct apply actions in the editor.

Check that you have permission to use a font before uploading it. A font cannot be deleted while a design or template uses it.

## Save layer-effect presets

1. Select a layer in a workspace design and open **Properties → Effects**.
2. Enter a name and choose **Save new** to save its blend mode, shadows, and outline.
3. On another layer, choose the preset and select **Apply**. Undo restores the previous effects. A preset cannot apply effects that the selected layer does not support.

Workspace editors can use **Rename preset**, **Replace effects**, or **Delete preset** to manage the library. Replacing or deleting a preset leaves previously applied layer effects unchanged.

To update an existing design after a template or brand change, open it and apply the new values. Use [version history](/image-editor/saving-and-recovery#version-history) before a large change.
