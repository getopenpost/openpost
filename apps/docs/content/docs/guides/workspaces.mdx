A workspace keeps a team's publications, connected accounts, schedules, media, and members together. Choose it from the workspace switcher before you create a post or inspect results. Content from another workspace will not appear here.

## Invite someone

Open workspace settings, invite the teammate, and choose their role. Roles control what they can do in that workspace:

| Role   | Access                               |
| ------ | ------------------------------------ |
| Admin  | Manage workspace access and settings |
| Editor | Create and manage workspace content  |
| Viewer | View workspace content and settings  |

An admin can change or remove access later. Removing a member does not delete the workspace's publications.

## Find settings

Use the workspace switcher for workspace members and connected accounts. Your profile menu holds personal sign-in and notification preferences. Instance settings are available to administrators of a self-hosted deployment.
