# README demo assets

- `risc-v-reference.jpg` is the thumbnail supplied by Rodrigo for this edit.
- `risc-v-logo.png` is the logo cropped from that reference. It keeps the source
  colors and white outline. The capture rebuilds the text and layout as editable
  layers instead of importing the finished thumbnail.
- `Bangers-Regular.ttf` is Vernon Adams's Bangers font from
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/bangers), licensed
  under the included `OFL.txt`.
- `tutorial-music.wav` is an original nine-second synthesized instrumental made
  for this capture. It has no external samples.

These files are capture inputs only. They are not shipped with the application.
