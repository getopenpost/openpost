title: Quickstart
description: Connect an account and publish your first OpenPost publication.
---

The hosted app needs no installation. Sign in at [app.openpo.st](https://app.openpo.st), create a workspace, and follow these steps.

## 1. Connect an account

Open **Settings → Workspace → Social accounts**, choose a platform, sign in, and approve access. [Bluesky](/guides/accounts#bluesky) is the quickest first connection because it uses an app password instead of a provider app review.

## 2. Create a publication

Choose **New post**, select the workspace and account, and write your text. Add media or a thread when needed. Review the destination preview before sending it.

## 3. Publish or schedule

Choose **Publish now** for an immediate delivery, or choose a date and time and select **Schedule**. Open **Calendar** to see scheduled work.

## 4. Check the result

Open **Publications** or the item in **Activity**. A publication shows each destination rendition as scheduled, publishing, published, or failed. Open a failed rendition for the provider error and recovery action.

## Self-hosted first run

Follow the [self-hosting quickstart](/self-hosting), then use the same four steps. The first account created on a new instance becomes its administrator.
