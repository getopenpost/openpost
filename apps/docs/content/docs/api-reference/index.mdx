The API is JSON and lives under `/api/v1`. The generated reference below is the contract used by the web app, CLI, MCP, and external automation.

## Authentication

Use a browser session for interactive work or a bearer API token for automation:

```http
Authorization: Bearer YOUR_TOKEN
```

Create and revoke tokens in **Settings → Personal → Developer**. Give a token one workspace scope when possible. Treat it like a password and store it in your automation's secret store.

## First request

Replace the URL with your OpenPost server:

```sh
curl https://app.openpo.st/api/v1/workspaces \
  -H "Authorization: Bearer $OPENPOST_TOKEN" \
  -H "Accept: application/json"
```

Use the returned workspace ID when an operation asks for one. Workspace access is checked for every private operation.
