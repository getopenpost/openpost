Open [Video Editor](https://app.openpo.st/video-editor) and choose **New project**. Pick a format and name the project.

Use a vertical format for Stories and short videos, a landscape format for standard videos or screen recordings, or enter custom dimensions.

## Choose where it is saved

| Choice            | Saved work                                                                            |
| ----------------- | ------------------------------------------------------------------------------------- |
| Saved to OpenPost | The project, revisions, and required original Project Assets in the current workspace |
| Local only        | The edit, sources, recordings, and exports in a folder you choose                     |

**Saved to OpenPost** is the signed-in default. Select **Keep available offline** to retain the current revision and its originals on this device. Playhead position, panel layout, previews, downloaded models, folder access, and exports you have not uploaded do not sync.

For **Local only**, choose a folder when the browser asks. Back up the whole folder and keep linked originals available. Clearing browser data can remove remembered folder access and temporary caches, but it does not delete the folder's files.

Project Assets are separate from Workspace Media. Only exports you save or send to Media appear in that library.

## Add your sources

1. Open **Media → Import media** and add video, audio, images, Lottie files, or supported subtitle tracks.
2. Select a source to place it on the timeline.
3. Play it in the preview to check picture and sound before editing.

Collected sources are copied into the project. Linked sources stay in their original location and must remain available for editing and export. Trimming and effects leave the originals unchanged.

A ProRes file that cannot play directly may use a local compatibility proxy for preview. Final export still needs the original.

## Find the controls

The left panel holds media and tools. The center shows the preview. **Properties** on the right changes the selected item. The timeline below holds clips, audio, captions, and adjustments.

Use **Edit**, **Color**, and **Motion** to switch tasks. Collapse or dock side panels to make room. These layout choices, selection, zoom, and playhead position stay on this device.

## Move or share a project

Importing a local project into OpenPost checks its sources and uploads only originals used by the timeline. It leaves the local copy intact.

Export an `.openpost.zip` bundle for a portable local copy with the project and required originals. Preview caches and downloaded models are not included.

See [recovery](/video-editor/browser-and-recovery) for missing sources, save conflicts, and deleted projects.
