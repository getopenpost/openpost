### Changed

- Screenshot templates (messages, group chats, receipts and status pages) now render on the server, so web, mobile and Workflows produce the same image. The preview updates as you type and keeps the last image on screen while the next one renders.
- Workflow and MCP post builds now finish planned screenshot templates and memes themselves instead of leaving the draft waiting for an image.
- Text card previews render about 25 times faster and keep the current cards visible while you type.
- Meme previews render 4 to 13 times faster.
- The Video Editor exports MP4 (H.264) by default. It uses the hardware encoder where one is available and is accepted by every supported network.

### Fixed

- Text cards and screenshot templates no longer leave wide gaps after emoji and CJK characters, and text cards show emoji in color.
- Screenshot templates made on mobile now match the web, including right-to-left text.
