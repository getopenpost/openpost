## Insert a variable

Required fields and unavailable variables show an inline error and a **Needs attention** badge on the node. Select the badge to open its configuration.

Type a value and add variables wherever you need them. Select **Insert variable** to search available fields, type `{{` for suggestions, or drag an input field into the editor. Variables appear as chips in both short and long text fields; unavailable fields are marked invalid. **Edit variable syntax** exposes the underlying paths.

## Keep the right data type

The preview uses the current sample or run data. In numeric, JSON, and condition fields, a single variable preserves its original type. Text fields turn numeric and boolean variables into text. Mixing variables with text also produces text.

## Inspect inputs and outputs

The node inspector opens in a large modal over the canvas, with input data on the left, settings in the middle, and output on the right. Switch between structure, table, and JSON views. Table view shows item collections as rows. On a phone, it opens as a sheet with three inspector tabs. Close it to return to the selected node.

## Transform data

Data nodes edit fields, transform text, parse JSON, filter/sort/limit lists, merge data, format dates, and add UTM tracking parameters. **Read RSS feed** fetches current feed items inside a workflow, useful for a weekly digest.

**JavaScript** receives the selected data as `input` and returns a JSON value. It runs in an isolated environment with a two-second deadline and a 32 MiB JavaScript heap. It cannot access the network, files, or host environment. Use **HTTP request** for API calls.

For a worked JavaScript example, [turn an API response into a post](/workflows/examples/api-to-post).
