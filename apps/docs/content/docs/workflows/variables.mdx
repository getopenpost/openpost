Use variables to pass a trigger's data or an earlier step's result into another step.

## Insert a value

1. Open the step and select a field.
2. Choose **Insert variable**, type `{{` for suggestions, or drag a field from the input panel.
3. Choose the source field. Use **Edit variable syntax** when you need to inspect its path.

Variables appear as chips. Unavailable fields show an error and **Needs attention** on the node.

A single variable in a numeric, JSON, or condition field keeps its original type. Text fields and variables mixed with text convert values to text.

## Inspect and transform data

The step inspector shows input, configuration, and output. Choose structure, table, or JSON view; table view shows collections as rows. Phones use tabs for these panels.

Data steps can edit fields, parse JSON, filter/sort/limit lists, merge values, format dates, or add UTM parameters. **Read RSS feed** fetches current feed items.

**JavaScript** receives `input` and returns a JSON value. It has a two-second deadline and a 32 MiB heap, with no network, file, or environment access. Use **HTTP request** for API calls.

See [the API-to-post example](/workflows/examples/api-to-post) for a short transformation.
